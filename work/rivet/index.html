About.

Rivet is an AI agent that lives on your Android phone. Give it a task in plain words and it gets to work — writing code, running a real terminal, browsing the web, using your files and apps — and shows you everything it did along the way. Bring your ChatGPT plan, your own API keys, or a model that runs entirely on your phone. No account needed to start.

See moreSee less

What makes it different:

  • A real agent, not a chatbot. Rivet plans multi-step work, uses its tools, and checks the result before it answers. Ask for an app, a script, research, a fix — it works until there’s something to show.
  • A full terminal on your phone. A real Linux shell with git and build tools built in. No Termux, no setup rituals.
  • It can use your phone. With your permission it opens apps, reads and writes files in folders you approve, takes screenshots, and can drive Termux if you have it.
  • Your ChatGPT plan works here. Sign in with ChatGPT and use the models your plan already pays for — inside an agent that can actually do things with them.
  • Or don’t use the cloud at all. Download an open model once and run it fully offline. Rivet is honest about what your phone’s RAM can handle, before you download anything.
  • Help that scales. Big jobs split across sub-agents working in parallel, using models you pick. Long projects survive for days because Rivet compacts its own memory into checkpoints instead of forgetting.
  • Projects, not just chats. Every conversation works on a real folder of files. Start from ready-made starter projects, and when a file is finished it arrives as a card — tap it and read it side-by-side with the chat.
  • Open source. Apache-2.0. Free. The code is public and the app is yours.

FAQ.

Is Rivet free?

Yes — free and open source (Apache-2.0). There’s no Rivet account and nothing to unlock. The only cost is the model you choose to run it with: your existing ChatGPT plan, your own API keys, or a free on-device model.

Do I need a ChatGPT subscription?

No. If you have one, Rivet can use it. If you don’t, API keys (DeepSeek, OpenRouter, and others) work, and on-device models work with no account at all.

Does Rivet work offline?

With an on-device model, yes — the agent runs entirely on your phone. Cloud models need an internet connection, like any cloud service.

What phones does it run on?

Android 8.0 and above. For on-device models, more RAM means bigger models — Rivet shows you what fits before you download.

Is my data private?

Your chats and project files stay on your phone. If you use a cloud model, your prompts go to that provider under their privacy policy — the same as using their own app. On-device models send nothing anywhere.

Why isn’t Rivet on the Play Store?

It’s on the way. Until then, this page carries the official APK — the same file as on GitHub — and Rivet updates itself in-app when a new version lands.

How do I install it?

Download the APK, open it, and allow "install from this source" if Android asks. That’s it — no root, no PC, no cables.
